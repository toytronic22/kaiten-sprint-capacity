# Ёмкость спринта

Закладка для досок Kaiten [Staff Core](https://dodopizza.kaiten.ru/space/19143/boards?focus=board&focusId=68084) и [Staff Mobile](https://dodopizza.kaiten.ru/space/19143/boards?focus=board&focusId=1321013). Доска выбирается в шапке панели, браузер запоминает последнюю. Правила расчёта у досок одни, только на Staff Mobile вместо фронта — Mobile. Нажали — справа открылась тёмная панель: нагрузка по бэку, фронту и QA против возможного.

```
Бэк    20 + 28 = 48 / 30
Done   25%
```

Осталось с прошлого спринта + прибавилось = сейчас / можно. Перебор — красным, белая черта на полоске — где кончаются возможные.

## Начать планирование

Кнопка запоминает, сколько SP осталось в работе: вся доска без Done и без багов. Дальше «прибавилось» растёт весь спринт: новые карты, переоценка хвостов, смена оценок. Правило команды с 29.09.2026.

Карты, бывшие в Done на момент нажатия, больше не считаются нигде: при закрытии спринта они уходят в архив. Бывает, что спринт закрывают в конце планирования, — на цифры это не влияет. Такую карту вернули из Done в работу — она снова считается.

Снимок общий на всю команду: панель пишет его комментарием в служебную карту [71238243](https://dodopizza.kaiten.ru/71238243) «⛔⛔⛔ Не трогать» и берёт оттуда последний для выбранной доски. У каждой доски свой снимок. Нажать ещё раз — снимок заменится у всех. Время снимка — рядом с кнопкой, кто нажал — в подсказке.

## Установка

1. Открыть [страницу установки](https://toytronic22.github.io/kaiten-sprint-capacity/) и перетащить кнопку «Ёмкость спринта» на панель закладок.
2. Открыть доску в Kaiten и нажать закладку. Нажать ещё раз — панель закроется.

Вышла новая версия — перетащить кнопку заново: закладка хранит код в себе и сама не обновляется.

Токен не нужен: панель работает на странице Kaiten и ходит в его API под вашим входом, как сам Kaiten. Ничего не отправляет наружу. Единственная запись — комментарий со снимком в служебную карту по кнопке «Начать планирование».

## Что вводить руками

- Людей и отсутствия (в человеко-днях) — по бэку, фронту и QA.
- Рабочих дней и праздников в спринте.
- SP на человеко-день — потолок, по умолчанию 1.

Панель «Команда и дни» открыта, пока не вписаны люди. Вписанное хранится в браузере на этом компьютере, у каждой доски своё.

## Как считает

- **Вся доска**, включая Done, кроме карт, бывших в Done на начало планирования.
- **Оценки.** Две разные оценки (Size и Story Points): большая — общая, разработка + QA; меньшая — разработка; QA — разница. Неважно, в каком поле какая. Оценка одна или обе равны — целиком в разработку, QA 0. Правило команды с 29.09.2026.
- **Платформа.** Есть Backend — в бэк. Иначе Frontend — во фронт, на Staff Mobile вместо него Mobile. Иначе разработка не считается, карта в «Проверить».
- **Done отдельно:** сумма SP в Done, а жирным — процент по числу карт: карт в Done от всех карт доски вместе с багами, до целого. Пришла новая карта — процент меньше. Правило команды с 29.09.2026.
- **SP багов не считаю** — ни в нагрузке, ни в сумме Done, ни в замечаниях. В процент Done баги идут как карты. Баг — тип «WEB bug» или слово bug/баг в названии типа. Правило команды с 29.09.2026.
- **Возможные** = (люди × (рабочие дни − праздники) − отсутствия) × SP на человеко-день.
- **Проверить** — карты без платформы Backend или Frontend (на Staff Mobile — Mobile) (их разработка не считается), Need QA без оценки QA и карты без оценки.

- **Беспредел.** «Сейчас» хотя бы в одной строке вдвое больше «можно» — по экрану с криком «Беспредел!» бегут гуси, мигает «C-C-C-COMBO BREAKER!», через 5 секунд всё пропадает. Размер подстраивается под окно, звук на 40% тише обычного. Один раз, пока беспредел не кончится и не начнётся снова.

Данные обновляются сами раз в минуту, пока вкладка на экране, ↻ — сразу. Время обновления — в шапке.

## Ограничения

- В фоновой вкладке не обновляется — обновится, когда вернётесь.
- Только доски 68084 и 1321013. Номера досок, служебной карты, полей и типа бага — в `SPRINT_CAPACITY` в `src/core.js`.
- Служебную карту не переносить в архив и не удалять её комментарии: без неё «осталось» пропадёт у всех.

## Разработка

- `npm test` — тесты. Снимок доски на планировании 28.09.2026 — в `test/fixtures`.
- `npm run build` — собирает `dist/sprint-capacity.js`, `dist/bookmarklet.txt`, `dist/install.html`. Пуш в `main` сам выкладывает страницу установки.
- `src/core.js` — расчёт, без браузера. `src/kaiten.js` — запросы к Kaiten. `src/ui.js` — панель.
