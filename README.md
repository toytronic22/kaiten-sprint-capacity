# Ёмкость спринта

Закладка для досок Kaiten [Staff Core](https://dodopizza.kaiten.ru/space/19143/boards?focus=board&focusId=68084) и [Staff Mobile](https://dodopizza.kaiten.ru/space/19143/boards?focus=board&focusId=1321013). Доска выбирается в шапке панели, браузер запоминает последнюю. Правила расчёта у досок одни, только на Staff Mobile вместо фронта — Mobile. Нажали — справа открылась тёмная панель: нагрузка по бэку, фронту и QA против возможного.

```
Бэк    20 + 28 = 48 / 30
Done   25%
```

Осталось с прошлого спринта + прибавилось = сейчас / можно. Перебор — красным, белая черта на полоске — где кончаются возможные.

## Начать планирование

Кнопка запоминает, сколько SP осталось в работе: вся доска без Done и без багов. Дальше «прибавилось» растёт весь спринт: новые карты, переоценка хвостов, смена оценок. Правило команды с 29.09.2026.

Карты, бывшие в Done на момент нажатия, больше не считаются нигде: при закрытии спринта они уходят в архив. Бывает, что спринт закрывают в конце планирования, — на цифры это не влияет. Такую карту вернули из Done в работу — она снова считается.

## Закончить планирование

Кнопка появляется после «Начать планирование». Нажали — панель запоминает, сколько SP стало в конце планирования. Дальше у каждой строки рядом с названием жёлтая метка «сверху +5» — сколько прилетело за спринт после планирования: новые карты и переоценки. Эти SP по-прежнему идут в «прибавилось» и в «сейчас», на полоске они жёлтые. Нажать ещё раз — «сверху» считается заново от текущей доски. Новое «Начать планирование» сбрасывает конец планирования.

Снимок общий на всю команду: панель пишет его комментарием в служебную карту — как и конец планирования — [71238243](https://dodopizza.kaiten.ru/71238243) «⛔⛔⛔ Не трогать» и берёт оттуда последний для выбранной доски. У каждой доски свой снимок. Нажать ещё раз — снимок заменится у всех. Время снимка — рядом с кнопкой, кто нажал — в подсказке.

## В Holst

Кнопка в панели. Двигает бомбу сегодняшнего дня на процент Done и раскладывает розовый список по колонкам Kaiten на доске Holst «P2P General» — у Staff Core и Staff Mobile каждая в своём месте. Потом открывает доску, итог — сверху в Kaiten.

Один раз на компьютере нужен вход в Holst:

1. Перетащить со [страницы установки](https://toytronic22.github.io/kaiten-sprint-capacity/) вторую кнопку «Вход в Holst» на панель закладок.
2. Нажать «В Holst» в панели — появится поле «вход Holst».
3. Открыть любую доску Holst, нажать закладку «Вход в Holst» — она скопирует вход.
4. Вернуться в Kaiten, вставить вход в поле, нажать «Сохранить».

Дальше «В Holst» работает в одно нажатие. Вход хранится только в этом браузере. Holst перестал его принимать — панель скажет и попросит вставить заново. Старая закладка «Спринт → Holst» теперь тоже просто копирует вход.

## Установка

1. Открыть [страницу установки](https://toytronic22.github.io/kaiten-sprint-capacity/) и перетащить кнопку «Ёмкость спринта» на панель закладок.
2. Открыть доску в Kaiten и нажать закладку. Нажать ещё раз — панель закроется.

Обновлять закладку не нужно: при каждом нажатии она берёт свежую версию панели со страницы установки. Перетащить заново нужно один раз — тем, у кого закладка поставлена до 29.09.2026.

Токен Kaiten не нужен: панель работает на странице Kaiten и ходит в его API под вашим входом, как сам Kaiten. С GitHub Pages только загружает свой код. Записей две: комментарий в служебную карту по кнопкам «Начать планирование» и «Закончить планирование» и доска Holst по кнопке «В Holst» — только туда уходит вход Holst.

## Что вводить руками

- Людей и отсутствия (в человеко-днях) — по бэку, фронту и QA.
- Рабочих дней и праздников в спринте.
- SP на человеко-день — потолок, по умолчанию 1.

Панель «Команда и дни» открыта, пока не вписаны люди. Вписанное хранится в браузере на этом компьютере, у каждой доски своё.

## Как считает

- **Вся доска**, включая Done, кроме карт, бывших в Done на начало планирования.
- **Оценки.** Две разные оценки (Size и Story Points): большая — общая, разработка + QA; меньшая — разработка; QA — разница. Неважно, в каком поле какая. Оценка одна или обе равны — целиком в разработку, QA 0. Правило команды с 29.09.2026.
- **Платформа.** Есть Backend — в бэк. Иначе Frontend — во фронт, на Staff Mobile вместо него Mobile. Иначе разработка не считается, карта в «Проверить».
- **Done отдельно:** жирным — процент, тот же, что у бомбы дня (см. «Прогресс спринта»), под ним — сколько карт в Done из всех и сумма SP в Done. Правило команды с 30.09.2026.
- **SP багов не считаю** — ни в нагрузке, ни в сумме Done, ни в замечаниях. Баг — тип «WEB bug» или слово bug/баг в названии типа. Правило команды с 29.09.2026.
- **Прогресс спринта** — процент Done в панели, по нему же двигается бомба дня. Каждая карта весит свои SP (разработка + QA, как в нагрузке), любой баг и карта без оценки — 1 SP. Готовность по колонке: To Do 0%, Doing 30%, Review 65%, Design Review и Test 80%, Waiting for release 97%, Done 100%. Прогресс — сумма «вес × готовность» от суммы весов, до целого. Карты, бывшие в Done на начало планирования, не считаются. Колонку не из списка считаю как To Do и называю в панели и в плашке Holst. Бомбу дня скрипт всегда ставит по прогрессу, даже если её подвинули руками. Правило команды с 30.09.2026.
- **Розовый список в Holst** — карты спринта по блокам колонок, у багов 🐞 в начале. Подсвечены карты, которые сменили колонку со вчерашнего утра (с 00:00 прошлого рабочего дня) — даже если потом вернулись обратно, и новые карты: жёлтая — в работе, зелёная — в Done, рядом «← из колонки, время». В понедельник, субботу и воскресенье «вчера» — это пятница. Окно одно на весь день, повторное нажатие подсветку не снимает. Правило команды с 30.09.2026.
- **Возможные** = (люди × (рабочие дни − праздники) − отсутствия) × SP на человеко-день.
- **Проверить** — карты без платформы Backend или Frontend (на Staff Mobile — Mobile) (их разработка не считается), Need QA без оценки QA и карты без оценки.

- **Беспредел.** «Сейчас» хотя бы в одной строке вдвое больше «можно» — по экрану бегут гуси и машут крыльями. Трое кричат «Беспредел!» и бегут в разные стороны. Один влетает в экран и расплющивается почти на весь экран, под плашкой: вспышка, фонтаны и потёки крови, трещина на стекле остаётся до конца. Мигает плашка «!!Overload!!» и сменяется на «Бэк трещит!», «Frontend трещит!» (на Staff Mobile — «Mobile трещит!»), «QA трещит!» — по тем строкам, где перебор. Через 5 секунд всё пропадает. Размер подстраивается под окно, без звука. Один раз, пока беспредел не кончится и не начнётся снова.

Данные обновляются сами раз в минуту, пока вкладка на экране, ↻ — сразу. Время обновления — в шапке.

## Ограничения

- В фоновой вкладке не обновляется — обновится, когда вернётесь.
- Только доски 68084 и 1321013. Номера досок, служебной карты, полей и типа бага — в `SPRINT_CAPACITY` в `src/core.js`.
- Служебную карту не переносить в архив и не удалять её комментарии: без неё «осталось» пропадёт у всех.

## Разработка

- `npm test` — тесты. Снимок доски на планировании 28.09.2026 — в `test/fixtures`.
- `npm run build` — собирает `dist/sprint-capacity.js`, `dist/bookmarklet.txt`, `dist/install.html`. Пуш в `main` сам выкладывает страницу установки.
- `src/core.js` — расчёт, без браузера. `src/kaiten.js` — запросы к Kaiten. `src/ui.js` — панель.
- `src/holst-core.js` — список и бомба для Holst, без браузера. `src/holst.js` — запись в Holst по его сокету. `src/holst-login.js` — закладка «Вход в Holst».
