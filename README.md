# Ёмкость спринта для Kaiten

Панель-закладка для досок Kaiten. Показывает, сколько работы взяли в спринт по бэку, фронту и QA и сколько
команда успеет с учётом отпусков и праздников. Фиксирует план на старте спринта, считает отчёт о спринте
и выгружает цифры на доску Holst.

> Это открытая копия для портфолио. Номера досок, полей и карт, адрес Kaiten и доски Holst заменены выдуманными.
> Рабочая версия живёт в закрытом репозитории команды.

## Что умеет

- **Ёмкость.** SP на доске по ролям против «людей × рабочие дни − отпуска» × «SP в день». Перебор — строка красная.
- **Планирование.** Снимок на старте спринта; всё, что прилетело потом, и переоценки видны отдельно.
- **Отчёт спринта** по четырём вопросам — результат, предсказуемость, время доставки, качество. Только данные
  Kaiten: история колонок, оценки, баги по источнику.
- **Проверка данных.** Карты без оценки, без платформы, с Need QA и нулевой оценкой QA.
- **Holst.** Процент готовности над графиком, отчёт и список карт по колонкам на доске команды. Над колонками
  календаря — бомбы с процентом по истории Kaiten, флажок START в день старта, звезда растёт с процентом.
  Цель спринта из Kaiten — подписью на картинке.
- **Подсказки.** Спринт закончился, а в Kaiten не завершён — панель сама ставит плашку на доску Holst.
- **Дейлик.** Очередь по кругу с ведущего, рычаг со звуком двигает её и показывает, кто говорит. Ведущий
  и список общие для команды через служебную карту, у Core и Mobile свои.
- **Три скина:** подземелье с живым огнём, классика, единороги. Панель тянется уголком, помнит вкладку
  и размер, обновляется сама.
- **Календарь.** Праздники и переносы РФ 2026–2027, сутки по Москве, смена шкалы SP с 12.10.2026.

## Как устроено

- Закладка при каждом нажатии грузит свежую сборку с GitHub Pages — переустанавливать её после правок не нужно.
- Данные — REST API Kaiten с сессией пользователя. Общие настройки команды панель хранит комментариями
  в служебной карте Kaiten и сама удаляет свои старше четырёх дней.
- Запись в Holst — через его WebSocket API. Вход передаётся из вкладки Holst во вкладку Kaiten через
  `postMessage` с проверкой origin.
- Чистый JavaScript без зависимостей; Node.js — только для тестов и сборки.
- Картинки и звуки дейлика в этой копии свои, сгенерированные; подземелье пишет системным Palatino, единороги —
  шрифтом Balsamiq Sans с jsDelivr.

## Тесты

320 тестов на встроенном `node:test`: расчёты, отчёт спринта на обезличенной фикстуре настоящего планирования,
раскладка Holst, очередь дейлика и smoke-тесты собранной панели в `node:vm` с заглушками браузера. GitHub Actions гоняет их
на каждый пуш и PR.

```bash
npm test
npm run build
```

Сборка кладёт в `dist/` панель, скрипт для Holst, закладку, страницу установки, справку и файлы дейлика.
