# Ёмкость спринта для Kaiten

Панель-закладка для досок Kaiten: сколько работы взяли в спринт по бэку, фронту и QA и сколько команда успеет
с учётом отпусков и праздников.

> Открытая копия для портфолио: номера досок, полей и карт заменены выдуманными. Рабочая версия — в закрытом
> репозитории команды.

## Что умеет

- **Ёмкость** по ролям против «люди × рабочие дни − отпуска». Перебор — строка красная.
- **Снимок плана** на старте спринта: что прилетело потом, видно отдельно.
- **Отчёт спринта** по истории Kaiten: результат, предсказуемость, время доставки, качество.
- **Выгрузка в Holst:** процент готовности, отчёт и карты на доске команды.
- **Дейлик:** очередь по кругу с рычагом, три скина.

## Как устроено

Чистый JavaScript без зависимостей. Данные — REST API Kaiten с сессией пользователя, запись в Holst — через его
WebSocket. Закладка при каждом нажатии грузит свежую сборку с GitHub Pages.

```bash
npm test        # 320 тестов на node:test, в CI — на каждый пуш и PR
npm run build   # сборка в dist/
```

Подробно — [как пользоваться и как считает](docs/USAGE.md).

Требования, сценарии и проверка — мои; код и тесты писал вместе с Claude Code.
