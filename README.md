# Ёмкость спринта

Закладка для доски Kaiten [Development(P2P)](https://dodopizza.kaiten.ru/space/19143/boards?focus=board&focusId=68084). Нажали — справа открылась панель: нагрузка спринта по бэку, фронту и QA против возможного.

```
Бэк: 8 + 34 = 42 из 28
```

Осталось с прошлого спринта + добавили = нагрузка из возможных. Перебор — красным.

## Установка

1. Собрать: `npm run build`.
2. Открыть в браузере `dist/install.html` и перетащить кнопку «Ёмкость спринта» на панель закладок.
3. Открыть доску в Kaiten и нажать закладку. Нажать ещё раз — панель закроется.

Токен не нужен: панель ходит во внутреннее API Kaiten под вашей сессией и только читает.

## Что вводить руками

- Людей и отсутствия (в человеко-днях) — по бэку, фронту и QA.
- Рабочих дней и праздников в спринте.
- SP на человеко-день — потолок, по умолчанию 1.
- Остаток по хвостам, если он меньше полной оценки.

Вписанное хранится в браузере на этом компьютере. Остатки — отдельно для каждого прошлого спринта.

## Как считает

- **Оценки.** Story Points — разработка. Общая оценка (Size) — разработка + QA. QA = Size − Story Points, не меньше нуля.
- **Платформа.** Есть Backend — в бэк. Иначе Frontend — во фронт. Иначе разработка не считается, карта в «Проверить».
- **Хвост** — карта из прошлого спринта, у которой оценки не менялись с его конца. Переоценили — считается добавленной. Пустой остаток — считаю полную оценку.
- **Конец прошлого спринта** — раньшее из планового конца и фактического закрытия.
- **Done** не считаю. Галочка «считать карты в Done» включает.
- **Баги не считаю совсем** — ни разработку, ни QA, ни хвосты, ни замечания. Баг — тип «WEB bug» или слово bug/баг в названии типа. Правило команды с 29.09.2026.
- **Возможные** = (люди × (рабочие дни − праздники) − отсутствия) × SP на человеко-день.
- **Не посчитано** — SP, которые некуда отнести: общая оценка без Story Points, Story Points без платформы.

Данные обновляются сами раз в минуту, пока вкладка на экране. Кнопка «Обновить» — сразу.

## Ограничения

- Открывается 4–5 секунд: прошлый спринт грузится целиком, до ~7 МБ.
- В фоновой вкладке не обновляется — обновится, когда вернётесь.
- Только доска 68084. Номера доски, полей и типа бага — в `SPRINT_CAPACITY` в `src/core.js`.

## Разработка

- `npm test` — тесты. Снимок доски на планировании 28.09.2026 — в `test/fixtures`.
- `npm run build` — собирает `dist/sprint-capacity.js`, `dist/bookmarklet.txt`, `dist/install.html`.
- `src/core.js` — расчёт, без браузера. `src/kaiten.js` — запросы к Kaiten. `src/ui.js` — панель.
