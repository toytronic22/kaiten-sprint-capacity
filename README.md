# Ёмкость спринта

Закладка для доски Kaiten [Development(P2P)](https://dodopizza.kaiten.ru/space/19143/boards?focus=board&focusId=68084). Нажали — справа открылась панель: нагрузка всей доски по бэку, фронту и QA против возможного.

```
Бэк: 48 из 28
В Done: 25%
```

Нагрузка из возможных. Перебор — красным. Под итогами — доля Done от всей доски.

## Установка

1. Собрать: `npm run build`.
2. Открыть в браузере `dist/install.html` и перетащить кнопку «Ёмкость спринта» на панель закладок.
3. Открыть доску в Kaiten и нажать закладку. Нажать ещё раз — панель закроется.

Токен не нужен: панель ходит во внутреннее API Kaiten под вашей сессией и только читает.

## Что вводить руками

- Людей и отсутствия (в человеко-днях) — по бэку, фронту и QA.
- Рабочих дней и праздников в спринте.
- SP на человеко-день — потолок, по умолчанию 1.

Вписанное хранится в браузере на этом компьютере.

## Как считает

- **Вся доска**, включая Done. Прошлый спринт и хвосты не учитываются. Правило команды с 29.09.2026.
- **Оценки.** Две разные оценки (Size и Story Points): большая — общая, разработка + QA; меньшая — разработка; QA — разница. Неважно, в каком поле какая. Оценка одна или обе равны — целиком в разработку, QA 0. Правило команды с 29.09.2026.
- **Платформа.** Есть Backend — в бэк. Иначе Frontend — во фронт. Иначе разработка не считается, карта в «Проверить».
- **Done отдельно:** SP и карты в Done, а жирным — процент: SP в Done от SP всей доски, до целого.
- **Баги не считаю совсем** — ни в нагрузке, ни в Done, ни в замечаниях. Баг — тип «WEB bug» или слово bug/баг в названии типа. Правило команды с 29.09.2026.
- **Возможные** = (люди × (рабочие дни − праздники) − отсутствия) × SP на человеко-день.
- **Не посчитано** — разработка карты без платформы Backend или Frontend.

Данные обновляются сами раз в минуту, пока вкладка на экране. Кнопка «Обновить» — сразу.

## Ограничения

- В фоновой вкладке не обновляется — обновится, когда вернётесь.
- Только доска 68084. Номера доски, полей и типа бага — в `SPRINT_CAPACITY` в `src/core.js`.

## Разработка

- `npm test` — тесты. Снимок доски на планировании 28.09.2026 — в `test/fixtures`.
- `npm run build` — собирает `dist/sprint-capacity.js`, `dist/bookmarklet.txt`, `dist/install.html`.
- `src/core.js` — расчёт, без браузера. `src/kaiten.js` — запросы к Kaiten. `src/ui.js` — панель.
